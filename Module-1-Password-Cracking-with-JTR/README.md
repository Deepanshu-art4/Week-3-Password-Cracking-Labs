# Module 1 - Password Cracking with John the Ripper (JTR)

## Overview

This practical assignment was completed as part of the NetworkWALKS Cybersecurity \& Ethical Hacking training program.

The objective was to understand password security testing using John the Ripper and its graphical interface, Johnny GUI.

## Tools Used

* John the Ripper 1.9.0 Jumbo
* Johnny GUI
* Windows 11
* PDF Hash Extractor

## Tasks Completed

1. Downloaded and extracted John the Ripper.
2. Installed Johnny GUI.
3. Configured the John the Ripper executable in Johnny.
4. Obtained the supplied password-protected PDF.
5. Extracted the PDF hash for the authorized lab.
6. Prepared the hash input file.
7. Loaded the lab hash into Johnny.
8. Completed the password-recovery exercise.
9. Verified access to the supplied PDF using the recovered password.

## Learning Outcomes

* Understanding PDF password protection.
* Learning about password hashes.

## Result

The assigned practical exercise was completed successfully, and access to the supplied PDF was verified using the recovered password.
