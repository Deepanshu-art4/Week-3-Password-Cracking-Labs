# Practical Report - Password Security Testing with John the Ripper

## 1\. Introduction

This practical was performed as part of Week 3, Project Module 1 of the NetworkWALKS Cybersecurity \& Ethical Hacking training program.

## 2\. Objective

To understand PDF password protection, password hash extraction, and the use of John the Ripper through its graphical interface, Johnny GUI, in an authorized training environment.

## 3\. Tools and Technologies

* John the Ripper 1.9.0 Jumbo
* Johnny GUI
* Windows 11
* PDF Hash Extractor

## 4\. Practical Procedure

1. Downloaded the John the Ripper Jumbo package.
2. Extracted the downloaded package.
3. Opened Johnny GUI.
4. Configured the John the Ripper executable.
5. Selected the supplied password-protected PDF.
6. Extracted its hash using the designated lab tool.
7. Prepared the hash input file.
8. Loaded the authorized lab input into Johnny.
9. Completed the assigned password-recovery exercise.
10. Verified access to the supplied PDF.

## 5\. Evidence

Seven practical screenshots are stored in the screenshots directory.

## 6\. Observations

* Johnny successfully detected the configured John the Ripper executable.
* The PDF hash was identified in the lab exercise.
* The practical recovery exercise was completed.
* The supplied PDF was successfully opened for verification.

## 7\. Result

The assigned practical was completed successfully. The password-protection and authorized password-recovery workflow was demonstrated.

## 8\. Learning Outcomes

* Understanding PDF password protection.
* Understanding password hashes.
* Familiarity with John the Ripper Jumbo.
* Familiarity with Johnny GUI.
* Importance of strong password practices.
* Practical cybersecurity documentation.

## 9\. Conclusion

This exercise provided practical exposure to password-security testing and demonstrated how password-protection mechanisms can be evaluated in an authorized educational environment.

## 10\. Disclaimer

All activities were performed for educational purposes using an authorized training lab. No third-party accounts, documents, or systems were targeted.
