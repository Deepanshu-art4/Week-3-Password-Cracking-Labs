\# Module 2 – Password Cracking with NetworkWALKS Tools



\## Overview

This practical assignment was completed as part of the NetworkWALKS Cybersecurity \& Ethical Hacking training program.



The objective was to understand PDF hash extraction and password-security testing using NetworkWALKS tools.



\## Tools Used

\- NetworkWALKS Hash Calculator

\- NetworkWALKS Password Cracker

\- Web Browser

\- Windows 11



\## Tasks Completed

1\. Downloaded the supplied password-protected PDF.

2\. Opened the NetworkWALKS Hash Calculator.

3\. Uploaded the PDF for hash extraction.

4\. Extracted the PDF hash.

5\. Saved the extracted hash as lab evidence.

6\. Used the NetworkWALKS Password Cracker for the authorized exercise.

7\. Obtained the password-recovery result.

8\. Opened the supplied PDF using the recovered password.

9\. Verified successful PDF access.
