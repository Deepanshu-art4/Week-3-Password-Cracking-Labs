# Practical Report - Password Security Testing with NetworkWALKS Tools

## 1\. Introduction

This practical was completed as part of Week 3, Project Module 2 of the NetworkWALKS Cybersecurity \& Ethical Hacking training program.

## 2\. Objective

To understand PDF password protection, hash extraction and password-security testing using the assigned NetworkWALKS tools in an authorized training environment.

## 3\. Tools Used

* NetworkWALKS Hash Calculator
* NetworkWALKS Password Cracker
* Web Browser
* Windows 11

## 4\. Practical Procedure

1. Obtained the supplied password-protected PDF.
2. Opened the NetworkWALKS Hash Calculator.
3. Submitted the PDF for hash extraction.
4. Reviewed the extracted hash output.
5. Saved the required lab evidence.
6. Completed the assigned password-security exercise.
7. Reviewed the recovery result.
8. Verified access to the supplied PDF.
