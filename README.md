# Week 3 - Cybersecurity & Ethical Hacking Labs

## Overview

This repository contains two completed practical assignments from the NetworkWALKS Cybersecurity & Ethical Hacking training program.

The assignments focus on PDF password security, hash extraction, and password-security testing using different tools.

## Project Modules

### Module 1 - Password Cracking with John the Ripper

**Tools:** John the Ripper Jumbo, Johnny GUI, PDF Hash Extractor.

- Configured John the Ripper with Johnny GUI.
- Extracted the PDF hash for the authorized lab.
- Completed the assigned practical exercise.
- Verified access to the supplied PDF.

[View Module 1](Module-1-Password-Cracking-with-JTR/)

### Module 2 - Password Cracking with NetworkWALKS Tools

**Tools:** NetworkWALKS Hash Calculator, NetworkWALKS Password Cracker.

- Extracted the supplied PDF hash.
- Completed the assigned password-security exercise.
- Reviewed the recovery result.
- Verified access to the supplied PDF.

[View Module 2](Module-2-Password-Cracking-with-NW-Tools/)
